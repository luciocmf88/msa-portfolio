# MSA — Scientific Analytics

**Research · Data Science · Geospatial Solutions**

Portfolio of **Lucio Medeiros**, bringing together environmental science, data analytics, geospatial workflows and scientific consulting. The full institutional name is **Medeiros Scientific Analytics**.

## Website

Planned URL: https://luciocmf88.github.io/msa-portfolio/

This website is built with [Quarto](https://quarto.org/) and hosted on GitHub Pages.

## Sections

- Home — overview of scientific and analytical expertise
- Projects — planned public case studies, clearly labeled as works in preparation
- Services — statistical analysis, GIS, visualization, technical review and automation
- About — professional background and approach

## Run locally

Install Quarto, then execute:

```bash
quarto preview
```

## Deployment

1. Commit or upload the files to the `main` branch.
2. In GitHub, open **Settings → Pages → Build and deployment**.
3. Select **GitHub Actions** as the source.
4. Open **Actions**, inspect the `Publish MSA website` workflow, and run it if necessary.
